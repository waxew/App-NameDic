# App-NameDic — نام‌نامه ایران

«نام‌نامه ایران» یک برنامه Android آفلاین و قابل توسعه برای شناخت نام‌ها، معنی/توضیح، ریشه زبانی، فرهنگ محل استفاده و میراث تاریخی ایران است.

## نسخه 1.0.1

- Kotlin + Jetpack Compose + Material 3
- minSdk 24 / targetSdk 36 / compileSdk 36
- AGP 9.3.0 / Gradle 9.5.0 / Java 17
- جستجو در نام، معنی، ریشه و برچسب
- تفکیک دخترانه، پسرانه، مشترک و نیازمند بررسی
- 16 دسته سطح‌بالای زبانی/فرهنگی
- بخش «اسامی اصیل ایرانی»
- بخش قهرمانان، اساطیر و جانوران/موجودات فرهنگی
- علاقه‌مندی‌های آفلاین
- Drawer جدید با پروفایل و انتخاب عکس با یک لمس
- Back صحیح از صفحات داخلی به صفحه قبلی/خانه
- About فقط شامل توضیح و نسخه است و package name را نمایش نمی‌دهد
- بررسی اختیاری نسخه جدید از `update.json`؛ دیتابیس نام‌ها همچنان آفلاین است

## اصل مهم داده‌ها

`Origin / ریشه` از `Usage Culture / فرهنگ استفاده` جداست. رایج بودن یک نام در یک جامعه، به تنهایی ریشه زبانی آن را اثبات نمی‌کند.

## دیتاست پایه

پروژه یک فایل پایه کوچک دارد تا بدون اینترنت فوراً اجرا شود. ابزار `tools/sync_names.py` دیتاست متن‌باز `nabidam/persian-names` را دریافت و `names_base.json` را با فهرست کامل 8,816 نام جایگزین می‌کند. معنی و ریشه جداگانه و با وضعیت اعتبار نگهداری می‌شوند.

```bash
python3 tools/sync_names.py
./gradlew :app:assembleDebug
```

کلید خصوصی واقعی در GitHub عمومی قرار نمی‌گیرد. برای جزئیات `signing/README.md` را بخوانید. برای آپدیت‌های آینده `applicationId` و کلید signing باید ثابت بمانند.
