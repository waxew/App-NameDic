# App-NameDic — نام‌نامه ایران

«نام‌نامه ایران» یک برنامه Android آفلاین‌محور برای جستجو، بررسی، پیشنهاد، پسندیدن و مقایسه نام‌های ایرانی و همچنین آشنایی با بخش‌هایی از تاریخ ایران است. برنامه تلاش می‌کند دادهٔ واقعی را از حدس جدا نگه دارد: معنی نام، ریشه، فرهنگ/فهرست استفاده و معنی واژهٔ هم‌نوشت چهار مفهوم مستقل‌اند.

## نسخه فعلی: 2.0.0

- `versionCode=11`
- Kotlin + Jetpack Compose + Material 3
- minSdk 24 / targetSdk 36 / compileSdk 36
- AGP 9.3.0 / Gradle 9.5.0 / Java 17
- دیتابیس آفلاین چندمنبعی با بیش از ۲۶ هزار رکورد نام
- `applicationId=ir.asteam.namedic` ثابت برای حفظ مسیر به‌روزرسانی

## انتخاب و بررسی نام

- تفکیک مستقیم اسم‌های دخترانه و پسرانه
- جستجو در نام، معنی، ریشه، دادهٔ واژگانی و نوشتار لاتین
- مرور «اسم پیدا کن» برای دیدن نام‌ها یکی‌یکی
- پسندیده‌های آفلاین با SharedPreferences
- انتخاب ۲ تا ۴ اسم از پسندیده‌ها و مقایسهٔ کنارهم
- نمایش جنسیت، معنی، ریشه، لاتین و فرهنگ‌های ثبت‌شده در مقایسه
- نام‌های مشابه بر اساس معیارهای قابل توضیح
- فرهنگ‌ها و زبان‌ها فقط وقتی نمایش داده می‌شوند که واقعاً داده داشته باشند
- اشتراک‌گذاری اطلاعات یک نام با Android Sharesheet
- گزارش ایراد داده با ایمیل از پیش آماده؛ برنامه چیزی را مخفیانه ارسال نمی‌کند

## پیشنهادگر پیشرفته 2.0

صفحهٔ مستقل «پیشنهادگر پیشرفته» بدون اینترنت روی corpus برنامه کار می‌کند و فیلترهای زیر را ترکیب می‌کند:

- جنسیت
- حرف اول واقعی موجود در داده
- عبارت داخل نام، معنی یا ریشه
- فرهنگ/فهرست منبع دارای داده
- فقط رکوردهای دارای توضیح
- پیش‌نمایش اختیاری `اسم + نام خانوادگی`

امتیاز داخلی موتور فقط برای مرتب‌سازی نتیجه‌های منطبق استفاده می‌شود و به‌عنوان محبوبیت، کیفیت یا ارزش یک نام به کاربر نمایش داده نمی‌شود.

## مرکز تاریخ ایران

نسخه 2.0 بخش قبلی «بزرگان تاریخ ایران» را به یک مرکز سه‌قسمتی تبدیل می‌کند:

1. **شخصیت‌ها:** ۳۵ شخصیت در دو بستهٔ محتوایی آفلاین، همراه نام، دوره، نقش، سال‌ها، خلاصهٔ بازنویسی‌شده، نکات مهم و لینک منبع.
2. **خط زمانی:** ۱۲ دوره/سلسلهٔ اثرگذار از مادها تا پهلوی، با توضیح اینکه برخی حکومت‌ها هم‌زمان یا منطقه‌ای بوده‌اند و Timeline یک زنجیرهٔ سیاسی بدون هم‌پوشانی فرض نمی‌کند.
3. **آزمون ایران‌شناسی:** سؤال‌های آفلاین که از همان دادهٔ شخصیت‌ها ساخته می‌شوند تا منبع آزمون با صفحات معرفی تناقض نداشته باشد.

اطلاعات تاریخی هرگز به معنی، ریشه یا فرهنگ یک «نام» تبدیل نمی‌شود.

## تنظیمات و به‌روزرسانی

- Drawer دارای پروفایل، تنظیمات، اشتراک با دوستان و مسیرهای اصلی برنامه است.
- کاربر می‌تواند بررسی خودکار نسخهٔ جدید در زمان اجرای برنامه را روشن/خاموش کند.
- بررسی دستی نسخه در Settings وجود دارد.
- شکست شبکه هیچ‌کدام از قابلیت‌های آفلاین را مسدود نمی‌کند.
- About فقط توضیح برنامه و نسخه را نشان می‌دهد و package name در UI نمایش داده نمی‌شود.
- Back navigation صفحات داخلی را به Home/صفحه قبلی برمی‌گرداند و از خروج ناخواسته جلوگیری می‌کند.

## اصل حیاتی داده‌ها

سه فیلد اصلی نام مستقل نگه داشته می‌شوند:

1. `meaning` = معنی یا توضیح مستقیم شخص‌نام با منبع مستقیم.
2. `origin` = ریشهٔ زبانی یا تاریخی منبع‌دار.
3. `lexicalMeaningFa` / `lexicalAntonymsFa` = اطلاعات واژهٔ فارسی هم‌نوشت با نام.

هم‌نوشت بودن یک واژه با نام، رایج بودن نام در یک فرهنگ و ریشهٔ زبانی آن ادعاهای متفاوت‌اند. برنامه هیچ‌کدام را از روی دیگری حدس نمی‌زند. خالی بودن معنی یا ریشه نیز به معنی نامعتبر بودن نام نیست؛ فقط یعنی هنوز دادهٔ مستقیم و منبع‌دار کافی به رکورد متصل نشده است.

## منابع و pipeline داده

منابع خودکار نام‌ها فقط زمانی وارد corpus می‌شوند که مجوز و provenance روشن داشته باشند. منابع فعلی شامل چند دیتاست نام ایرانی/فارسی، Wikidata، Wiktionary/Kaikki و Maani/Dehkhoda-Lexicon هستند. سامانه تعاملی ثبت احوال مرجع مهمی است، اما تا زمانی که API عمومی و شرایط برداشت ماشینی روشن نباشد bulk-scrape نمی‌شود.

دادهٔ تاریخی curated است: اطلاعات از منابع عمومی مانند Encyclopaedia Iranica، Wikipedia/Wikidata بررسی، سپس خلاصهٔ فارسی بازنویسی و لینک منبع اصلی در رکورد نگهداری می‌شود. مشاهدهٔ محتوای ذخیره‌شده به اینترنت نیاز ندارد.

### کنترل‌های CI

```bash
python3 tools/validate_data.py
python3 tools/validate_history.py
python3 tools/validate_history_timeline.py
python3 tools/sync_names.py
python3 tools/sync_mohammadhejazirad_names.py
python3 tools/restore_enriched_orphans.py /path/to/previous.json
python3 tools/sync_dehkhoda_lexical.py
python3 tools/sync_wikidata_cultures.py
python3 tools/sync_wiktionary_names.py
python3 tools/build_data_report.py
gradle :app:testDebugUnitTest
gradle :app:lintDebug
gradle :app:assembleDebug
```

GitHub Actions همین مراحل اصلی را به‌عنوان gate اجرا می‌کند و فقط پس از موفقیت Build، migration رابط را روی `main` persist می‌کند.

## فایل‌های داده و ماژول‌های مهم

- `app/src/main/assets/names_base.json`: corpus ادغام‌شده و deduplicate شده.
- `app/src/main/assets/curated_names.json`: رکوردهای پژوهش‌شدهٔ دستی.
- `app/src/main/assets/data_sources.json`: رجیستری ماشین‌خوان منابع.
- `app/src/main/assets/data_build_info.json`: آمار پوشش داده پس از build/sync.
- `app/src/main/assets/historical_figures.json`: بستهٔ پایه شخصیت‌های تاریخی.
- `app/src/main/assets/historical_figures_extra.json`: بستهٔ تکمیلی شخصیت‌های تاریخی.
- `app/src/main/assets/history_timeline.json`: خط زمانی منبع‌دار دوره‌ها و سلسله‌ها.
- `NameSuggestionEngine.kt`: موتور خالص پیشنهادگر آفلاین.
- `HistoryQuizEngine.kt`: موتور خالص تولید آزمون از دادهٔ شخصیت‌ها.
- `UpdateChecker.kt`: بررسی اختیاری نسخهٔ جدید.

## امضای Release

کلید خصوصی اصلی Release در GitHub عمومی یا CI قرار نمی‌گیرد. برای نصب نسخهٔ جدید روی نسخهٔ قبلی، `applicationId` و همان signing key اصلی باید ثابت بمانند. اگر keystore اصلی در محیط Build موجود نباشد، CI فقط APK Debug آزمایشی تولید می‌کند و هیچ کلید تازه‌ای برای جعل یک Release جدید ساخته نمی‌شود.
